# Crypto Tokenomics CLI

A command-line tool built with Node.js to fetch real-time crypto prices, Market Cap, and Fully Diluted Valuation (FDV) using the CoinGecko API.

## Features
- Real-time price tracking
- Market Cap vs. Fully Diluted Valuation (FDV) analysis
- Circulating token supply metrics
